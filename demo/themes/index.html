What to try
  • Tool cards. Run Fill the article, then flip Tool cards in the bar. The mode now applies to cards already on screen; each settled card separates Arguments from Result behind its own toggle.
  • Confirmation. The same run ends on a destructive Save article. The prompt appears inside the turn, disappears once answered, and the tool card keeps the decision.
  • A failing tool. Ask it to break something — the card settles to an Error region rather than losing the turn.
  • A question. Say ask me something to reach the built-in ask_user card.
  • Three approvals at once. Say import three rows: the server defers three create_event calls in one run and each is answered on its own. Every prompt is the same sentence, because a confirmation is written per tool — so each one renders inside its own card, above the arguments that say which row it is. Approve two and deny one; the cards settle differently. While they wait they read waiting for you, not running, since nothing is running.
  • A delegated sub-agent. Say delegate this: the run hands work to two sub-agents, and each delegate_task card grows a live row instead of sitting at running… for the whole wait. Open one to see the child's own tool calls, including the one that came back to it. The second delegation fails — the row says so and nothing more, because the reason is on the tool result underneath it.
  • Server-resolved skill. The Triage this article chip ships no prompt: it sends /triage and the server answers. Watch the request — the wording is never in this page.
  • Collapse. Hit the header's —: the panel scales into the round launcher in the corner, and the launcher expands it again. sidebar slides to an edge rail instead; embedded and page keep the header bar.
  • Chat history. The ☰ drawer slides in over the panel and back out — the same motion tokens drive both.
  • Unread badge. Collapse + ping collapses the widget and sends, so the answer lands behind the launcher and the badge counts it. Expanding marks it read. Uncheck Unread badge to see the opt-out — the count still runs (watch ag-ui-unread), only the dot is gone.
  • Resize. Drag the panel's top-left grip. Switch Placement to see the axes change: side is width-only, full and page have no grip at all.
  • Header icons / Deutsch. Both check that the chrome is host-replaceable and that every label comes from the string table.
