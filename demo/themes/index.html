0.47.0 additions

Four things the bar above has no room for. Each section has a control and a readout; the numbers beside them are read from the element, not kept here.

The above-composer slot

Host markup directly above the composer, below the chips, the hint, queued turns and the attachment tray. It takes no space while empty. Switch Placement to page and press New chat to see it travel with the centred composer.

empty

The place chip

getPlace names where the user is; the chip in the composer's tool row draws it and the next round sends it as a place context entry. Pick a place, then Where am I?: the mock agent quotes the entry it received. The eye on the chip withholds it (dashed, struck through), which also withholds the page map. A long one shows the label truncating before Send; None shows the chip taking no space.

The thread API

threadId is read-only; newChat() and switchThread() change the conversation, and each change fires one ag-ui-thread with a reason. Send a message or two, press newChat(), then pick the first thread back.

    Tool status parts

    Every tool card carries tool-card-status-<status> and every step group tool-group-<state>, so a host styles one outcome with ::part(). Tick the box to draw each in its own colour from this page. The census counts the parts in the transcript now. Reach each: Fill the article (done, then the group settles), break something (error), import three rows (deferred, the group waits; deny one for declined), delegate this (sub-agent error). Press Stop mid-run for interrupted. Needs Tool cards on grouped.

    census: no tool cards yet

    The focus ring token

    --ag-ui-ring is the step group head's focus outline (default: the accent at 55%). Pick a colour to set it on the element, then Tab to a group head (or press the button from the keyboard) to see it. Needs a settled step group: run Fill the article first.

    default

    The header hover square token

    --ag-ui-header-btn-hover draws the square behind a hovered header button exactly as given. Unset, the square follows the header text once the accent recipe sets it, and is the theme's own otherwise. Hover a header button to see it.
